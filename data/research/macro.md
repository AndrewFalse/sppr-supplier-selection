## 1. Курсы ЦБ РФ (USD, EUR, CNY)

**Источник:** официальный сервис ЦБ РФ `XML_dynamic.asp`, дата обращения 2026-10-03.
- USD: https://www.cbr.ru/scripts/XML_dynamic.asp?date_req1=01/01/2021&date_req2=03/10/2026&VAL_NM_RQ=R01235
- EUR: то же, `VAL_NM_RQ=R01239`
- CNY: то же, `VAL_NM_RQ=R01375`

**Метод:** `curl`, кодировка windows-1251 (разбор через `xml.etree`, объявленная кодировка обрабатывается корректно), запятая заменена на точку. Колонки: `date, currency, nominal, value_rub_per_nominal, rate_rub_per_unit` (`rate_rub_per_unit = value / nominal`).

**Проверки качества:**
- 1 422 строки на каждую валюту, 4 266 всего; пропусков (NaN) 0; дубликатов (date, currency) 0; наборы дат у всех трёх валют совпадают.
- Рассчитанный `rate_rub_per_unit` совпал с полем `VunitRate` самого ЦБ во всех строках (расхождений 0).
- **Номинал CNY:** в 2022 г. ЦБ временно публиковал юань с номиналом 10: 161 строка (2022-05-06; 2022-05-13…05-27; 2022-05-31…12-21; 2022-12-24…12-28; 2022-12-31; в остальные даты номинал 1). При использовании ряда брать только `rate_rub_per_unit`, не `value_rub_per_nominal`. USD и EUR: номинал всегда 1.
- **Скачки >15% за день:** не найдено. Максимальные изменения от записи к записи >10% (все в 2022 г.): USD +11,98% (2022-03-01), +12,54% (2022-03-03), −10,21% (2022-05-27); EUR +11,62% (03-01), +11,31% (03-03), −11,25% (05-27); CNY (нормализованный) +12,03% (03-01), +12,56% (03-03), −10,32% (05-27). Это реальные рыночные движения периода, а не ошибки данных; аномальных значений, требующих исправления, нет.
- Экстремумы (rate_rub_per_unit): USD 51,158 (2022-06-30) … 120,3785 (2022-03-11); EUR 52,7379 (2022-10-01) … 132,9581 (2022-03-11); CNY 7,69846 (2022-06-30) … 19,0415 (2022-03-11).
- Последние значения (2026-10-03): USD 83,4839; EUR 94,3201; CNY 12,4328.

**Особенности календаря (важно для моделирования):**
- Поле `Date` в XML — дата, с которой применяется курс. По данным (USD; даты у трёх валют совпадают): в ряду нет ни одного понедельника, зато есть 281 запись на субботы и 6 на воскресенья (вторник 273, среда 286, четверг 288, пятница 288). Похоже, курс, установленный в пятницу, получает дату субботы и действует до следующей записи (вторника). Для приведения к календарному ряду использовать forward-fill (вывод по наблюдению за данными, не из документации ЦБ).
- Крупные пропуски до 13 дней — новогодние праздники (2021-01-01 → 2021-01-12, 2025-12-31 → 2026-01-13 и аналогично в другие годы). Запись «2021-01-01» — курс, действовавший на начало года.

### 3.2 Как извлечено `rosstat_ppi.csv`

Файл ИЦП по ВЭД (6,56 МБ) формально превышает установленный лимит ~5 МБ, поэтому целиком он **не скачивался**. xlsx — это zip-архив, а сервер Росстата поддерживает `Accept-Ranges: bytes`: запросами `Range` получены только оглавление архива и нужные листы (суммарно сжатых данных ~3,3 МБ, меньше лимита). Листы: 3.1/3.3 (2021), 4.1/4.3 (2022), 5.1/5.3 (2023), 6.1/6.3 (2024), 7.1/7.3 (2025), 8.1/8.3 (2026); `x.1` — «на конец периода, в % к предыдущему месяцу», `x.3` — «в % к соответствующему месяцу предыдущего года».

Структура: до 2024 г. — строка на ВЭД; в 2025–2026 гг. после строки ВЭД идёт строка «Российская Федерация», затем федеральные округа и субъекты (взята только строка РФ, это проверялось утверждением в скрипте). 2026 г.: январь–август.

**Формат `rosstat_ppi.csv`:** `date, indicator, value`. `date` — первое число отчётного месяца (индекс «на конец периода», относится к месяцу). `indicator = ppi_{mom|yoy}_okved2_{код}`; `value` — индекс в % (100 = без изменений).

### 3.4 Техническая оговорка (TLS)

Сертификаты `rosstat.gov.ru` и `zakupki.gov.ru` выданы «Russian Trusted Sub CA» (Минцифры), корневого сертификата нет в системном хранилище macOS, `curl` без опций отвечает ошибкой 60. Для чтения публичных страниц и файлов выполнялись GET-запросы с `curl -k` (без проверки сертификата); логинов, форм и отправки данных не было, системное хранилище сертификатов не менялось. Целостность файлов подтверждается только внутренними проверками выше. `cbr.ru` и `fedstat.ru` открываются штатно.

Данные отдаются в XML по FTP (по поисковой выдаче с паспортов наборов: `ftp://free:free@ftp.zakupki.gov.ru/fcs_regions/`). FTP не проверялся (требует входа под логином, массовое скачивание не выполнялось).
- **robots.txt** (https://zakupki.gov.ru/robots.txt) содержит `Crawl-delay: 60`. Раскрытие: я узнал об этом после серии запросов; к `zakupki.gov.ru` отправлено ~20 одиночных GET-запросов (5 страниц поиска, 7 карточек контрактов по 2 страницы каждой, `robots.txt`) с интервалом 1,5–2 с, т.е. чаще рекомендованного. Массового скачивания не было, дальнейшие запросы прекращены.
- **Ограничения для аналитики:** текстовый поиск по «ИБП» возвращает много ремонта/обслуживания, нужны фильтры по КТРУ/ОКПД2 (в карточках встретились: ИБП 26.20.40.110-00000001; коммутатор 26.30.11.110-00000041; КВМ-консоль 26.20.16.190; системный блок 26.20.15.000-00000028). ## 7. Рекомендации по использованию в практике №6

- Курсы: привести к календарному ряду forward-fill; использовать `rate_rub_per_unit`; для месячной модели — среднее за месяц или значение на конец месяца (зафиксировать выбор).
- Ключевая ставка: ступенчатый ряд, forward-fill; потенциальные лаги влияния на закупочные цены задавать явно.
- ИЦП: по ключу «месяц» (`date` = 1-е число); для 2022-10…12 учесть сноску о территориях; для узких классов (26.2, 26.3, 27.9) не собирать накопленный индекс из м/м; пустое значение 2022-11 C г/г обрабатывать как пропуск.
- ИПЦ на ПК: только годовые значения; месячный ряд при необходимости выгрузить вручную из ЕМИСС (показатель 31074).
- Цены контрактов ЕИС использовать как наблюдения для калибровки порядка величин, а не как репрезентативную выборку; всегда проверять поле «Ставка НДС».

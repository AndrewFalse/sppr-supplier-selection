# СППР выбора поставщиков оборудования для диспетчерских комплексов

Сквозной учебный проект по дисциплине «Системы поддержки принятия решений».
Автор: Новосельцев Андрей Алексеевич, группа К4241.

**Предметная область.** Закупки комплектующих для типовых диспетчерских комплексов (стойки и пульты диспетчера) в крупном проекте; организация-пример - ООО «НИТА». ЛПР (лицо, принимающее решение) - директор организации.

**Категории оборудования и альтернативы:**

| Категория | Поставщики |
|---|---|
| ИБП (источник бесперебойного питания), стоечный 3 кВА | APC, Eltena, Vertiv, Piton |
| АВР (автоматический ввод резерва) | Elemy, Уралэнерготел, BONPET |
| КВМ-переключатели (клавиатура, видео, мышь) | Aten, Adder |
| Коммутаторы | HP (Aruba), Cisco, Eltex, MikroTik |
| Компьютеры и серверы | Lenovo, HP |

**Критерии:** k1 стоимость, k2 качество и технический уровень, k3 надёжность поставщика, k4 срок поставки, k5 гарантия и сервис в РФ, k6 санкционный риск канала, k7 российское происхождение.

## Данные

Все данные - из открытых источников:

- `data/raw/` - официальные курсы ЦБ РФ (USD, EUR, CNY, 2021-2026), ключевая ставка ЦБ РФ, индексы цен производителей Росстата;
- `data/research/` - сведения о поставщиках: статус на рынке РФ, каналы поставки, гарантия, публичные цены дистрибьюторов (с адресами страниц и датами обращения);
- `data/processed/alternatives.csv` - сопоставимые модели (по одной на поставщика в категории) с ценами, перепроверенными 13.10.2026; источники каждого значения - в `alternatives_sources.md`.

Показатели, по которым фактических данных нет (оценки 1-5 по k2, k3, k6, k7, часть сроков и гарантий), - экспертные оценки аналитика по явным правилам (`sppr/ratings.py`, `config/*.json`); они помечены как модельные. Поправки к сырым данным с обоснованием - в `config/data_adjustments.json`.

## Практики

| № | Практика | Результат |
|---|---|---|
| 1 | Постановка задачи | формальная постановка: ЛПР, цель, альтернативы, критерии, ограничения, источники данных; сбор открытых данных (`data/`) |
| 2 | Многокритериальный анализ | АНР-модель (метод анализа иерархий): матрица парных сравнений критериев, веса, ИС/ОС, итоговые приоритеты поставщиков; Excel-модель с живыми формулами (`outputs/p2/ahp_model.xlsx`) |

## Структура

```
config/      суждения ЛПР, оценки качества, поправки к данным, параметры моделей
data/        исходные (raw), собранные (research) и подготовленные (processed) данные
sppr/        расчётные модули
scripts/     запуск расчётов по практикам
outputs/     результаты по практикам (CSV, JSON, Excel, рисунки)
tests/       модульные тесты
tools/       сборка разделов паспорта СППР в Google Docs (Docs API)
```

## Запуск

```bash
pip install -r requirements.txt
python3 scripts/p2_ahp.py      # практика 2: АНР-модель -> outputs/p2/
python3 scripts/p2_excel.py    # практика 2: Excel-модель -> outputs/p2/ahp_model.xlsx
python3 -m pytest -q           # тесты
```

Сборка разделов отчёта (`tools/`) требует пакетов `google-api-python-client` и `google-auth`, ключа сервисного аккаунта в переменной `SPPR_GOOGLE_KEY` и ID документа в `SPPR_DOC_ID`; ключи в репозиторий не входят.
